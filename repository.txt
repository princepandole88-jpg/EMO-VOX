1. EXECUTIVE SUMMARY & PROBLEM STATEMENT

Commercial virtual assistants (e.g., Alexa, Siri) process user commands rigidly without recognizing the user's emotional or physical state. This creates robotic, tone-deaf interactions during moments of user stress, cognitive fatigue, or frustration.

EMO-VOX is a zero-budget, privacy-first desktop companion that bridges the gap between human affective states and digital voice assistants. By combining edge-based computer vision, speech synthesis, and cloud-based Large Language Model (LLM) reasoning, EMO-VOX evaluates facial expressions and vocal tone to adapt its conversational empathy, pacing, and assistance dynamically.

Key Objectives:
• Multimodal Sentiment Processing: Perform real-time facial expression classification alongside vocal audio parsing.
• Empathetic Context Injection: Dynamically alter LLM prompt conditions based on detected user mood.
• Edge-Based Data Privacy: Process facial feature extraction locally on the client machine to safeguard biometric data.

3. HIGH-LEVEL SYSTEM ARCHITECTURE & TECH STACK

Input Layer: Webcam (Video Stream) + Microphone (Audio Input)
    │
Processing Layer: OpenCV + DeepFace (Local Edge) + SpeechRecognition Module
    │
Reasoning Engine: Google Gemini API (Prompt Context Injection)
    │
Output Layer: CustomTkinter Dark GUI + pyttsx3 Speech Output

• Computer Vision Engine: OpenCV (frame extraction) & DeepFace (local facial expression classification).
• Audio & Speech Engine: SpeechRecognition / PyAudio (mic input) & pyttsx3 (offline text-to-speech output).
• Reasoning Engine: Google Gemini LLM API (empathic response generation via context injection).
• User Interface: CustomTkinter (frameless, floating dark-mode GUI with real-time visualizers).

4. KEY TECHNICAL DIFFERENTIATORS & NOVELTIES

1. Visual-Acoustic Congruence Engine ("Masked Emotion" Detection): Cross-references facial expression metrics against vocal pitch/volume variance to identify suppressed emotions (e.g., forced smiles masking high stress).
2. Temporal Emotional Inertia: Implements a 30-second rolling queue (moving average) to smooth frame-by-frame computer vision noise, facial occlusion, and transient blinking.
3. OS-Level Affective Automation: Triggers native OS actions during sustained user burnout (>2 minutes), such as activating "Do Not Disturb" mode, adjusting screen color temperature, or launching a quick relaxation prompt.
4. Zero-Cloud Biometric Privacy: Processes all webcam video streams locally on the edge device; personal interaction logs are stored in an encrypted local SQLite database.
5. Green AI Architecture: Handles standard system commands offline via rule-based logic, escalating to cloud LLM endpoints only when emotional or complex reasoning is required.
